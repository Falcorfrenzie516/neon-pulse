# Neon Pulse Alpha 0.1 — Basement Rave Vertical Slice

This is the first clean playable slice built around your Hell Escape-inspired structure.

## During the run
Two randomized tracks appear:
- Sound Check: +1 current-run weapon level
- Speakers: +1 current-run Beat
- Ticket Stub pile: earns Ticket Stubs
- Glow Stick pile: earns Glow Sticks
- Crew: choose one unlocked crew member

## Progression zone
After the run section:
- Merch Boxes: easier targets with random rewards
- Generators: tougher targets with random rewards
- Rare free Disco Ball drops can happen

## Between runs
- Ticket Stubs upgrade DJ stats
- Glow Sticks upgrade Crew
- Crew can be renamed
- Shop sells Standard Disco Balls
- Disco Balls can give Stubs, Glow Sticks, Merch, or Crew upgrades
- Festival Progress screen tracks your furthest stage
- Dying resets run upgrades but preserves permanent progression
